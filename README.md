# Soccer League Scheduling

A React-based application for managing soccer league schedules, teams, and matches.

## Getting Started

### Installation

1. Install dependencies:
```bash
npm install
```

2. Start the development server:
```bash
npm start
```

The app will open in your browser at `http://localhost:3000`.

### Project Structure

- `index.html` - Main HTML file
- `app.jsx` - Main React component with navigation and pages
- `styles.css` - Global styling with responsive design
- `package.json` - Project dependencies and scripts

### Features

- **Home Page** - Landing page with call-to-action
- **Schedule Page** - Display league schedule (ready for implementation)
- **Teams Page** - View teams with win/loss records
- **About Page** - Information about the application
- **Responsive Design** - Mobile-friendly layout

### Building for Production

```bash
npm run build
```

This creates an optimized production build in the `build/` folder.
